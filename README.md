# DeployCat OS
 
DeployCat OS is a lightweight Debian-based operating system that runs the [DeployCat](https://deploycat.app) game server manager. It boots directly into the DeployCat dashboard — no desktop, no browser, no setup required. Just flash the ISO to a USB, boot it, and you're managing game servers in under a minute.

Download the latest ISO from the here.
 
## Features
 
- **Instant dashboard** — boots straight into the DeployCat web UI on first power-on
- **No desktop needed** — runs headless on any x86_64 PC, server, or mini PC
- **One-click game servers** — Minecraft, Steam games, Hytale, and more
- **Automatic port forwarding** — UPnP/NAT-PMP built in
- **Remote access** — optional Tailscale tunnel integration
- **Auto-updates** — the OS checks for new DeployCat container images every 12 hours
 
## Minimum Requirements
 
- x86_64 processor (64-bit)
- 4 GB RAM (8 GB recommended for modded Minecraft)
- 32 GB storage (SSD recommended)
- USB flash drive (2 GB+) for installation
- Network connection (Ethernet recommended)
 
## Installation
 
1. Download the latest ISO from here.
2. Flash it to a USB drive using [Rufus](https://rufus.ie/) or [balenaEtcher](https://etcher.balena.io/)
3. Boot your PC from the USB drive
4. Follow the on-screen setup wizard
5. Access the DeployCat dashboard from another device on your network at `http://<deploycat-ip> etc.`
